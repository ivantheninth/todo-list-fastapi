# Todo List

Todo application built with FastAPI and PostgreSQL.

## Features

- Create tasks
- View tasks
- Update tasks
- Delete tasks

## Technologies

- FastAPI
- SQLAlchemy
- PostgreSQL
- HTML
- JavaScript

## Run

bash uvicorn api:app --reload 

Open:

text http://127.0.0.1:8000 

## API

- GET /tasks
- POST /tasks
- PATCH /tasks/{id}
- DELETE /tasks/{id}
